# Foldy promo

A 30.5 s silent promo, 1920×1080, built with [HyperFrames](https://github.com/heygen-com/hyperframes):
HTML compositions rendered frame by frame in headless Chrome. The result is
[`renders/video.mp4`](renders/video.mp4).

```bash
make video          # from the repo root: render the fold media, check, render the MP4
npx hyperframes preview   # from this folder: Studio in the browser
```

Needs Node 22+ and ffmpeg. The CLI is pinned to `hyperframes@0.8.36` in `package.json` and the
Makefile, so a re-render matches.

## Where things are

| File | What it holds |
| --- | --- |
| `BRIEF.md` | The confirmed brief: promo, ~30 s, 16:9, no sound |
| `STORYBOARD.md` | Six frames, each with its on-screen copy and a time-coded shot sequence |
| `frame.md` | The look: the site's tokens (`#ECEDF2`, `#0A84FF`, SF Pro), glass pills |
| `compositions/frames/NN-*.html` | One sub-composition per frame |
| `index.html` | The assembled timeline and the hoisted videos |
| `assets/` | Fold media from `Scripts/video-assets.sh` |

Every image of the fold is the app's own shader, rendered by `foldy-snapshot`: the overlay window
is `sharingType = .none`, so it cannot be recorded, and a CSS imitation would not be the product.
Change the fold, rerun `make video-assets`, render again.

## Before you re-run the assembler

`index.html` was edited by hand after `assemble-index.mjs` wrote it. Running the assembler again
drops these, and each one was a visible bug:

- The frame-1 fold video sits **before** `#el-01-close-the-lid` and starts at 0.3 s. Hoisted
  videos otherwise paint over their frame, and "Close the lid." disappeared under the fold.
  Frame 1's ground is transparent for the same reason.
- The two frame-4 videos have distinct ids (`…-video-3`, `…-video-4`); the assembler gave both
  the same one (`duplicate_media_id`).
- The frame-4 videos sit at `top:120px` to match the still in that frame, so the opening lid
  clears the headline.

## Not committed

- `assets/fonts/SFNS.ttf` is the macOS system SF Pro. It is Apple's, so the script copies it
  in on each Mac and `.gitignore` keeps it out.
- `capture/` (the site crawl), `snapshots/` and `.hyperframes/frame-packets/` are working state
  from the HyperFrames workflow and are regenerated by it.
